# Token I/O Decoupling

本项目维护面向 Pi Coding Agent 的 Coding Hooks Skill，以及编译、验证和本地更新脚本。两条路线由 YAML 定义，16 份 Hook 合同提供触发条件、所需证据和验收条件。Multimodal 内容作为参考资料提供。

按[安装与更新](INSTALL.md)生成本地 Skill。从 `SKILL.md` 进入，按当前路线和适用的 Hook 阅读指令。
