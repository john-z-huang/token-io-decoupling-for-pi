# 可选导航与详细 owner

## 触发条件

进入入口模块；选择当前规则/模块路径；或实际工具返回能力缺失。

## 执行要求

1. Extension 确定七模块及当前检查点，只加载当前模块清单与强相关 Hook，不预加载整个 Skill。Hook 为压缩执行合同，Markdown owner 保留详细权威；边界/冲突/细节未覆盖时定向查 owner，而不是从 Hook 省略推导豁免。
2. 导航、建议及结构检查是可选辅助，不授权、证明身份或替代检查点语义判断。不适用时记录理由并直接依据可读 owner；必需 owner 不可读才阻断依赖分支。
3. 工具经真实 searchTools/describeTool/describeNamespace 或 tool_search 发现，使用实际 Schema；hidden 不可旁路，不能硬编码其他宿主前缀。已选受保护路径失败时不得以直接写入/换身份绕过。
4. MCP Server 的旧身份、child effort、结构提取及安装契约本轮未迁移；不得输入伪造旧宿主 Session/runtime/model 值。Extension 入口、Hook 和本地检查通过不是 MCP 已支持 Pi 的证据。

## 退出与阻断

能直接获得当前权威规则及下一检查点才推进；不为可选工具不适用阻断无依赖工作。

## 重新核验

规则 Hash、模块形状、工具 Schema/暴露范围或能力改变时重核。
