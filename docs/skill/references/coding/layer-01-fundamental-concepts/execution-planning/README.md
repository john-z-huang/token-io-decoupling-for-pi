## 范围与边界

任务分配与输出路由、决策上下文/建议、决策门禁、工作流模块契约、规划和计划记忆生命周期。本分类管理规划与语义决策边界，不管理阶段控制或运行时专属绑定。

## 入口

方向未决时从决策门禁开始。调用有界可复用模块时应用工作流模块契约；其他情况按任务选择规划或执行主体分配 owner。
