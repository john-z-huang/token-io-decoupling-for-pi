获准创建新子代理时，由Root按实际任务在 `gpt-6.1-sol`、`gpt-6.1-terra`、`gpt-6-luna` 中选择实际可用的模型与推理强度，不再全部固定为Luna。选择和职责分开：同一职责可因任务不同选不同模型；换模型不产生授权、独立性或新的可用名额，不改变父级模型或MCP内部固定API模型。

以下“官方定位/支持值”来自三份官方模型卡；“任务与档位参考”是本Skill的路由启发，不是官方基准、性能保证或强制档位：

| 模型 | 官方定位 | 任务与档位参考 |
| --- | --- | --- |
| [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) | 接近Astra的复杂工作能力、较低成本；面向复杂编码及专业工作 | 跨模块实现、复杂修复/依赖推理、高风险或并发验证通常可考虑medium/high；明确且窄的实现也可low。不是所有Primary/Verifier固定Sol。 |
| [GPT-6.1 Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra) | 快速高效的视觉推理、精确computer use、清晰自然写作；例如图纸理解、文本起草修订 | 获准静态图片/图纸证据、文字/Skill文档可考虑low/medium；多约束视觉推理可high。模型卡的computer use能力不解除本Skill禁令，也不授权普通文档委派。 |
| [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) | 面向聚焦、高吞吐任务的高效模型 | 有界事实提取、分类、重复性机械修改、规则明确的实现/检查可考虑low/medium；有证据表明足够时也可承担其他职责，不以便宜代替充分性。 |

三者卡片均支持文本/图像输入、文本输出。Sol/Terra卡片明确不支持原生音频/视频，不能把静态帧分析当原生视频能力；具体输入仍按实际provider/宿主核验。Sol/Terra工具调用要求Responses API；Luna在Chat Completions中仅none支持function calling，带推理工具任务应使用实际兼容的Responses接口。模型可用不证明当前provider/工具链满足这些条件。

官方 `reasoning.effort`：Sol支持 `low/medium/high/xhigh/max`，Terra与Luna另外支持 `none`；三者卡片默认均为medium。Pi用 `thinking`，其 `off` 对应关闭推理意图，不把API的none直接塞进Pi参数；以实际模型的档位映射为准。三者没有minimal档。大致参考：简单、确定且容易检查的任务从low考虑；一般多步任务medium；实质复杂性、较高风险、边界/并发与困难反例可high。xhigh/max只在额外推理对当前任务确有必要且资源允许时选择；不是每次失败都依序升档，更高档不能弥补缺失证据/权限。

Root在创建前审阅任务目标/输入类型、复杂度、依赖、不确定性、风险/验证要求、输入量及延迟/成本约束，并简述选择依据；不按角色、文件数或名字机械选择。新任务可重新评估；已创建身份不得仅为换模型而重复创建/替换，同一子代理follow-up不重新核验模型设置。无真实续接能力时遵守一次性任务与终态名额不回收规则，错误/效果未知先读回，不通过改模型重放。

仅对真实支持的Schema传参。例如旧增强版subagent在已确认 Root 使用 `openai` 时使用 `model: "openai/gpt-6.1-sol:medium"`；`@mjakl/pi-subagent@3.1.0` 使用 `calls[]`，其每项model与thinking独立。`coding_delegate.jobs[].model` 保留前述后缀格式，适配器对新版拆成 `model: "openai/gpt-6.1-sol"` 与 `thinking: "medium"`，防止代理/启动默认档位覆盖显式选择。Root 使用 `openai-codex` 时应选择该 provider 下已核验可用的精确模型 ID，而非照抄 `openai/` 前缀。调用值覆盖配置文件；精确provider/model ID和受支持档位须在创建前核验，不模糊匹配、不静默钳制或回退。通用未增强工具只能继承或固定配置，不能靠task里的文字控制模型。请求值是配置意图，宿主报告值也不是受保护身份证明；不要求子代理自报。模型卡核对记录与适配边界见仓库 `integrations/pi-subagent/`；官方页面可更新，重大任务按需核对最新卡片。
