反馈使用共享计划证据时，应用[任务计划 Memory 生命周期](../execution-planning/task-plan-memory-lifecycle.yaml)：在该 owner 规定的阶段、交接、暂停或完成边界，通过获准的当前记录者或已释放贡献路径记录实质进展和带来源事实。普通进度汇报及阶段内的检查或修复，不单独触发持久化或全文读回。影响授权、范围、验收、方向或依赖动作的事实，仍须在受影响动作前记录并分析。反馈携带准确计划身份、持久化确认及 owner 要求的核验证据，不重复全文或改变释放权。缺少必需访问、持久化失败或必需核验失败时，暂停受影响边界；仅已记录的持久化限制可使用该 owner 的例外。
