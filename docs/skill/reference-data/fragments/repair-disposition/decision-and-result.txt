4. 重大决策变化应向调用方返回变更后的 Contract/Decision 事实和证据，以便重新审查 Contract 与 Decision 并调度路线。无具体失败时，返回 Repair `Not applicable` 及证据依据。若已验收的 epoch 发生变化，依赖工作继续前必须取得当前 Verification 证据。
