应用[Repair Disposition](../../layer-03-workflow-checkpoints/repair-disposition.md)。具体失败必须有诊断、受影响路径和最小候选；之后依次应用[Repair Scope Gate](../../layer-02-workflow-concepts/verification-and-repair/repair-scope-gate.md)、[Repair Execution](../../layer-02-workflow-concepts/verification-and-repair/repair-execution.md)及[Repair Verification Handoff](../../layer-02-workflow-concepts/verification-and-repair/repair-verification-handoff.md)。仅执行已授权的窄范围修复，保留实际变更路径/证据，并将新指纹/受影响 epoch 返回 VR01 进行当前重验。Contract 或 Decision 实质变化时，返回 `needs_prerequisite` 给调用方进行语义审查和调度；不得把它当作修复。无具体失败时，以证据依据记录 Repair `not_applicable` 并返回 VR01，确认当前 Verification 结果。诊断、授权、有界范围、修复证据或交接缺失时，阻塞依赖工作。
