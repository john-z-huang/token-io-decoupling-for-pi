应用[Verification Independence](../../layer-02-workflow-concepts/verification-and-repair/verification-independence.yaml)和[Session 职责归属](../../layer-01-fundamental-concepts/session-runtime/session-role-ownership.yaml)。Contract 要求独立 Change Verification Session 时，使用该职责并仅提供给定范围证据和验收条件；否则将同 Session 检查分类为逻辑验证。在 Multi-Agent 执行中，Worker/子代理实际正文或结果是实施证据，不是独立验证；复用或完整可见也不满足必需的独立验证。必需的独立性不可用时返回 `needs_prerequisite`；不得声称满足 Contract。
