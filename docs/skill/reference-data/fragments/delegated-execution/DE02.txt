应用[任务分配](../../layer-01-fundamental-concepts/execution-planning/task-assignment.md)和[执行者选择](../../layer-03-workflow-checkpoints/executor-selection.md)，再应用[输出 Token 路由](../../layer-01-fundamental-concepts/execution-planning/output-token-routing.md)及[输出路由选择](../../layer-03-workflow-checkpoints/output-route-selection.md)。仅当执行者结果为 `new-executor-needed` 且 Root 输出已处置时进入 DE03。已确认 Root 执行者或已确认的现有执行者/子代理，必须先确认输出已处置，再根据该证据将角色预留记录为 `not_applicable` 并继续至 DE04。必需结果未知或未解决时返回 `needs_prerequisite`；冲突则阻塞。不得把未解决视为 `not_applicable`。
