仅对新子代理应用[子代理创建](../../layer-01-fundamental-concepts/delegation/delegation-child-creation.yaml)和[运行环境与模型厂商支持](../../layer-01-fundamental-concepts/session-runtime/runtime-provider-support.yaml)。确认符合条件的已释放任务/Slice、唯一角色预留、当前容量、能力、权限、上下文、返回条件及必需运行环境/effort 证据；只创建已授权子代理。独立创建型扩展在派发前按 owner 绑定实际身份/allocation；同步一次性扩展在此完成创建前核验并标记已批准、尚未调用的 allocation，不虚构提前返回的身份。后者在 DE06 以同一次工具调用创建、派发、执行并返回，再将真实调用/结果证据绑定该 allocation。两种路径均在依赖前更新并回读父级记录，不能重复调用来补造身份。复用现有子代理时，根据复用证据将创建和新 model-binding 检查记录为 `not_applicable`；保留相同身份，不重查模型选择，也绝不替换。已确认 Root 执行时，将子代理创建/身份记录为有原因的 `not_applicable`。所有分支进入 DE07；子代理分支先经过 DE06。已由当前证据确认 Root 执行时，可共用一次执行者选择记录，说明职责预留、创建、派发三个检查点不适用。仍须通过 DE04 放行和 DE07 结果审阅。
