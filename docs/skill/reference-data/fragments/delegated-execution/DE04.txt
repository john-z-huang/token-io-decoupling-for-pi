所有实际执行者分支都经过此检查点。应用[执行控制](../../layer-01-fundamental-concepts/execution-control/execution-control.md)、[执行规划](../../layer-01-fundamental-concepts/execution-planning/execution-planning.md)和[委派状态记录](../../layer-01-fundamental-concepts/delegation/delegation-state-record.md)。实质变化会使依赖它的 Control 证据失效；释放/恢复前返回 DE08 并重新评估当前事实。`Stop` 会阻塞。子代理执行时核验当前容量/allocation；Root 执行时记录附有理由的子代理容量 `not_applicable`。仅当 Context 和 Decision 当前有效，并明确目标、已授权执行者/角色、范围/修改、返回条件、未释放边界及新 Worker bundle 的显式 memo 值时，才释放具体 Slice。恢复既有 bundle 时保留并核验记录值。子代理行动前按 owner 更新并回读规范 parent-context 记录。若无实质 Control 变化，记录附有理由的 `not_applicable`。释放前应用[任务计划 Memory 生命周期](../../layer-01-fundamental-concepts/execution-planning/task-plan-memory-lifecycle.md)；必需证据、持久化或核验失败时阻塞依赖工作。
