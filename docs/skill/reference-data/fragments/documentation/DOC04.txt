在任何请求的 Memory 写入和 owner 要求的内容核验之后，结合前后指纹应用[Documentation Impact](../../layer-03-workflow-checkpoints/documentation-impact.md)及[Verification Epoch](../../layer-02-workflow-concepts/verification-and-repair/verification-epoch.md)。实际维护文档/注释/Memory 变化推进 documentation epoch。若无输出变化且指纹匹配，不推进 epoch，并以证据记录 `not_applicable`。仅推进受影响维度，保留未受影响证据理由。可执行内容、Contract 或验收变化还须分类为 implementation/content 影响，并返回当前 Verification。影响未知时阻塞。
