所有现有或未来 Coding 路线，以及执行任务工作的独立模块，都消费[任务计划 Memory 生命周期](task-plan-memory-lifecycle.yaml)。必要事实/决策分析后、实施或依赖派发前建立具体共享计划；模块之间传递准确项目/名称、当前计划证据、持久化确认及 owner 要求的核验证据。遵循该 owner 的更新和贡献边界，包括验证和需求变化；普通汇报或模块切换不单独触发写入或全文读回。影响授权、范围、验收、方向或依赖动作的事实，仍须在受影响动作前记录并分析。明确持久化限制按该 owner 记录例外；没有可选规划意图绝不豁免此依赖。缺少必需计划/访问、持久化失败或必需核验失败时阻塞依赖效果，不重放已完成模块效果。
