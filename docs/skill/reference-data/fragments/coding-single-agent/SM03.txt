调用[工作定义模块](modules/work-definition.md)，解决当前 Context、Decision、规划输出及有界授权工作。在 WD02，独立于 Decision 建议考虑可选[工作流路由建议](../layer-01-fundamental-concepts/execution-planning/workflow-routing-advice.md)：仅在事实当前且已直接确认锁定路线时使用，并根据该路线审阅建议；未选择或不符合条件时，记录有原因的 `not_applicable`。该建议不授权工作，也不改变路线。所选路径缺少必需能力或证据过期时，返回以取得当前证据或阻塞该依赖路径。仅在来源事实、已接受决定和未释放边界当前时继续。缺失事实/决定交其 owner 处理并恢复 SM03；授权或 Contract 实质变化时交调用方审查路线。执行前要求该模块返回默认共享计划身份、当前计划证据与持久化确认，或有记录的持久化限制例外；完成 owner 要求的任何内容核验。必需计划证据缺失时阻塞；无需额外规划请求。验证所选仓库存储范围及对应活动/归档命名空间；共享存储时，同仓库各工作区指向同一规划，其他仓库保持隔离。映射未知或冲突时返回规划 owner，不得静默回退另一存储范围。
