带上 SM01–SM03 证据及 continuation/effect 状态，调用[Single-Agent 执行模块](modules/single-execution.yaml)。在 SE03，仅当当前执行者、输出 class、capability、单独授权、固定 root、路径和 baseline 符合各自 owner 时，才使用[输出物料化](../layer-01-fundamental-concepts/execution-planning/output-materialization.yaml)和[候选合规预检](../layer-01-fundamental-concepts/execution-planning/candidate-compliance.yaml)：同一候选须经过同一 root/政策下的新鲜 whole-batch 预检后再应用，并根据实际当前文件审阅收据。未选择可选路径时，记录有原因的 `not_applicable`，且仅在独立授权的直接路径下继续；已选必需检查/能力失败、未知、过期或不确定时阻塞依赖操作。这些结果仍是 SM05 的初步证据。仅在当前实施结果和初步证据齐备时继续。该模块负责执行者/输出解析、Slice 释放、实施、阶段反馈和 Control，不能创建或派发子代理。证据请求、修订或下一 Slice 时保留 Control continuation 和恢复位置。携带共享计划身份和当前证据；模块确认所需职责的计划访问权限，按 owner 规定的边界记录更新，并在依赖工作/汇报前完成 owner 要求的内容核验；包括需求修订在内，影响依赖工作的变化须在该工作前记录。
