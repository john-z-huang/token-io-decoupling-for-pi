每个分配角色都应用[任务计划 Memory 生命周期](../execution-planning/task-plan-memory-lifecycle.yaml)。派发指明准确项目与共享计划、允许贡献，以及实际获准的当前记录者写入轮次。Worker 仅确认已释放职责所需的访问；复用当前计划上下文，或在该 owner 的刷新条件触发时取得所需内容。在 owner 定义的边界，通过获准记录者或贡献路径提交带来源事实与进展；普通进度汇报不单独触发写入或全文读回。需求变化先记录再分析，分析/修订提议持久化并完成 owner 要求的核验后，才请求父级释放。影响授权、范围、验收、方向或依赖动作的事实，须在受影响动作前记录并分析。此具名贡献与 root 记录及可选执行 memo 分离，不授予源码/同级访问或 Contract 权威。验证者仅可贡献验证事实。缺少必需访问、持久化失败或必需核验失败时阻塞依赖工作，须向父级报告。
